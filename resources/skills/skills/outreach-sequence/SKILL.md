# Outreach Sequence

## When to use

A ranked account needs messages that generate a meeting, not a brochure. Triggers: `draft the sequence`, `write the cold email`, `LinkedIn DM for this CTO`.

## What it does

Picks one opening offer, writes a one-sentence spine, then a 3–4 message sequence plus optional LinkedIn layer and a short objection set.

## Steps

1. Choose **one** opening offer that matches the pain (free diagnostic, paid audit, workshop, case-review). Do not stack offers.
2. Write the spine: "For [segment] dealing with [pain], we run [offer] that delivers [outcome] in [timeframe]."
3. Message 1 — trigger-anchored, under 120 words, soft ask. No specific calendar slot; Calendly **or** "20 minutes next week?"
4. Message 2 (3–5 days) — different angle, one new piece of value.
5. Message 3 (5–7 days) — reference prior notes, harder ask or breakup.
6. Optional LinkedIn: connection request under 300 characters. Do not connect and pitch in the same breath.
7. Role variants for Tier A only (CEO / COO / CTO / data / security) — same spine, different emphasis.

## Output

Spine, then Message 1–3, LinkedIn connection + follow-up, objection replies for: not ready, no budget, send more info, already have a vendor.

## Guardrails

Do not fabricate personalization (a "trigger" you cannot cite). Do not name a meeting time. Do not attach a 12-slide deck as the CTA — a one-pager or a 20-minute call. Keep the sender's voice direct; no em-dash ornament, no "just circling back" empty of content.
