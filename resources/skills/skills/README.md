# Skills

Each subdirectory is an [Agent Skill](https://agentskills.io/specification): at minimum `SKILL.md` with YAML frontmatter (`name`, `description`) and a markdown body.

The directory name must equal the `name` field. Optional extra files (`examples.md`, `reference.md`, `scripts/`) are listed on the skill's catalog page.

See `../CONTRIBUTING.md` to add one.
