# AI Workflow Templates — Roadmap

## Shipped (0.1)

- 16 templates from ARC operator packages, Blueprint Labs list, and portfolio register
- Searchable, filterable browse UI with HITL badges
- Read-only JSON API + open content repo
- Per-template detail pages, copy Markdown / copy prompt
- Structural dry-run (required-field check, no model call)
- CLI search (`npm run catalog`)
- Catalog integrity tests

## Next

- Runnable reference implementations per template (starter snippets in-repo)
- Cost / latency notes per template
- Provider-specific variants (OpenAI, Anthropic, local)

## Later

- Eval harness per template (gold input → expected JSON)
- Template versioning + per-item changelog
- Optional live run behind an API key you bring
