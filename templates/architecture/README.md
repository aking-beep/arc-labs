# Architecture template

Written at `stage: building` — not before. Experiment code does not get an architecture
document; that is the point of experiment code.

Copy `ARCHITECTURE.md` into the product's directory (and it travels with the code when
the product graduates to its own repository).

Keep it to decisions and their reasons. A diagram of what the code obviously does is
maintenance work with no payoff; a record of *why* the boring option was chosen is worth
rereading in a year.
