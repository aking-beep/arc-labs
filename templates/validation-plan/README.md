# Validation plan template

Written when a record moves to `stage: validating` — the point where real people who do
not work at ARC start using the thing.

Copy `PLAN.md` to the work directory (`experiments/<domain>/<id>/VALIDATION.md`) and fill
it in *before* recruiting anyone. A validation plan written after the data arrives is a
narrative, not a plan.

Clears [Gate 3](../../docs/GRADUATION_CRITERIA.md#gate-3--prototype--validating).
