# Launch checklist template

The last gate. Completed when a product passes
[Gate 5](../../docs/GRADUATION_CRITERIA.md#gate-5--incubate--graduate) and leaves Labs
for its own repository.

Copy `CHECKLIST.md` to `incubator/building/<id>-launch.md`, work it to completion, then
graduate. An unchecked box is a blocker, not a note — if something genuinely does not
apply, strike it with a one-line reason rather than ticking it.
