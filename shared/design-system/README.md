# Design system

Tokens and primitives so an experiment does not spend its timebox on buttons.

Deliberately thin. A Labs design system that tries to cover every product's needs becomes a product of its own, and then the experiments are blocked on it.

## Scope

- Tokens: colour, type scale, spacing, radius, motion
- Primitives: button, field, surface, stack, text
- Dark and light, both correct, because [Principle #6](../../docs/PRODUCT_PRINCIPLES.md) is a gate
- Accessible by construction: focus states, contrast, hit targets, reduced-motion

## Out of scope

- Product-specific layouts and page compositions
- Brand expression for a graduated product — that travels with the product
- Anything only one experiment has ever used
