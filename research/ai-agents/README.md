# AI agents

Agentic systems: tool use, planning, reliability, evaluation. The reading behind the `ai` domain. Note the boundary — making autonomous systems *trustworthy in operation* is ARC Control's mandate. Labs' interest is what agency does for a person's capability.

## Current questions

- Where an agent raises a person's capability rather than replacing their judgement
- What makes agent output inspectable enough that a user can stay the decision-maker
- Evaluation that predicts real-world behaviour rather than benchmark performance
- Cost and latency curves, and what they make viable that was not viable last year
