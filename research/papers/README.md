# Papers

Notes on specific papers. One file per paper, named `YYYY-MM-firstauthor-shorttitle.md`.

A note here is not a summary — abstracts already exist. It answers three things a summary does not: **what this changes for Labs**, **whether the result survives the paper's own limitations**, and **whether anyone has replicated it**.

## Current questions

Add a paper here when it changed how someone thinks about a record. A paper nobody can
connect to a Labs question does not need a note, however good the paper is.
