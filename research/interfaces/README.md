# Interfaces

Interaction, input modalities, and legibility. How a person tells a system what they want, and how the system shows what it did. Cuts across every Labs domain, which is why it has its own directory rather than living under one of them.

## Current questions

- Making model output legible enough to be trusted — and distrusted accurately
- Input beyond text and tap: voice, gesture, ambient, sensor
- Showing uncertainty without either hiding it or paralysing the user
- Latency as communication ([Principle #8](../../docs/PRODUCT_PRINCIPLES.md)): what a wait teaches the user
