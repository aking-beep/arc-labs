# Emerging technology

Scouting notes. Is it real yet, and what specifically is blocking it? Every note is dated, because the answer changes and a reader needs to know how stale it is.

The highest-value note in this directory is usually a **"not yet, and here is the specific blocker"** — it saves someone a timebox and it names the condition that should reopen the question.

## Current questions

- What crossed a cost or capability threshold in the last 18 months
- What is one threshold away, and which specific threshold
- What has been promised for three years and has not moved — and why
- Infrastructure shifts that change what an application can assume

---

One file per note, named `YYYY-MM-topic.md`. Format in
[`research/README.md`](../README.md): the question, what we found, what it implies for
Labs, what we still do not know — dated, attributed, confidence-rated.
