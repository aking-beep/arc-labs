# Changelog

All notable changes to ARC Skills are documented here. Format based on Keep a Changelog; this project follows semver.

## [0.1.0] - 2026-08-11
### Added
- Initial public release: 6 seeded agent skills across Engineering, Operations, Productivity, Support, and Quality.
- Browsable, searchable catalog UI with category filters.
- Static per-skill detail pages with source links.
- Read-only JSON API at `/api/catalog`.
- CLI search (`npm run catalog`).
- Optional email capture for update notifications.
