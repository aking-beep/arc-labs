# building/ — `stage: building`

Decided `incubate`. Evidence cleared the validation gate and this is becoming a real
product — still inside Labs, but no longer an experiment.

**What changes at this stage:**

- All ten [product principles](../../docs/PRODUCT_PRINCIPLES.md) apply, not just 1–3 and 7
- A product owner is accountable for the product, not just the experiment
- A [product brief](../../templates/product-brief/) exists
- An [architecture document](../../templates/architecture/) gets written
- Experiment-grade code gets replaced rather than extended — hardcoded shortcuts were
  correct then and are debt now

**Typical duration:** one to two quarters. This is the longest stage and the one most
likely to stall, which is why it keeps a `review_by` date like every other non-terminal
stage.

**Exit:** [Gate 5](../../docs/GRADUATION_CRITERIA.md#gate-5--incubate--graduate) and the
[launch checklist](../../templates/launch-checklist/). Graduation moves the code out of
Labs entirely.

Supporting documents for a record here are named `<id>-brief.md` and `<id>-launch.md` so
they sit beside the record. They are read by people, not by the validator.
